# Sites 迁移说明

## 范围

独立、仅所有者可访问的雅思听写 Site。本地版本及七分路径不变。
本次不改界面、词库、练习规则，也不添加跨设备账户同步。
`src/` 的 204 个文件、`public/dicts/` 的 380 个文件均与本地当前版本逐字节一致。

## 必要适配

- 保留 React/Vite，生产构建把发音与诊断地址设为同站 `/audio`、`/events`，不再依赖本机 8787 端口。
- 新增兼容 Workers 的服务入口；保留有道/DictionaryAPI 并发备援、口音匹配、1 秒前台截止、4 秒预加载截止、请求合并、缓存及熔断。
- 后台在线请求在前台超时后可继续完成，供后续请求命中缓存。
- MP3 为只读发布资产：4,751 个片段，118,795,739 字节，全部 SHA-256 与本地原文件一致，无重编码。未匹配的 37 个词继续走原备援链，315 个待确认词的标签不变。
- 页面播放诊断写入私有 R2；服务端来源、缓存和失败诊断写入 Worker 日志。学习记录仍保存在当前浏览器。
- 在独立副本中统一为实际使用的 npm 锁文件；补齐原锁文件缺失的依赖。修正首次 Git 提交尚不存在时构建等待不返回的问题。原项目文件不变。

## 使用与数据迁移

1. 旧本地网站：齿轮设置 → 数据设置 → 导出数据，保留 `.gz` 备份。
2. 新 Site 登录后：同一位置 → 导入数据，选择备份。导入将覆盖新网站当前的练习数据。
3. 导出包含练习记录、章节记录、复习记录和动态词本。显示、发音等偏好属于浏览器设置，需要在新站重新选择。
4. 手机或其他浏览器的数据不会自动同步。不要清理新站浏览器数据，建议定期导出备份。
5. 云端访问不需要本机开发服务器运行。本地版仍可单独使用。

- 动态词本与学习记录从本地 5173 网站导出、在 5190 生产预览的全新浏览器上下文导入验证。
- 动态词本、释义偏好、听写后释义反馈共 26 项页面回归。
- 服务端路径限制、原文件响应、缓存、来源切换、超时后后台完成、诊断持久化及存储失败状态共 8 项测试。
- 原仓库 `npm test` 是占位脚本，不把它计为测试通过；保留旧浏览器测试的既有失败说明，不声称整个历史测试套件全绿。
- 自动检查能验证音频字节、解码及播放时间推进，不能替代扬声器/耳机实际听感。

外部依据：Cloudflare 官方 Workers 静态资产绑定及限制文档。原 MP3 是已生成的只读发布资产，适合随构建发布；新增的运行期诊断使用 R2 持久化。既有设备本地学习记录按已确认范围保留，未改为云端账户记录。

本次品牌验证：最终生产构建成功；桌面、手机（原头像解码及尺寸）和章节结束页品牌检查通过，成绩分享入口与 Excel 下载保留。4751 片段 SHA-256、字节数及同站端点校验通过。广泛页面回归29/34通过，4项播放遥测超时和1项键盘自动化超时；后者独立复测通过。新旧产物真实Audio对照均有成功播放，也都出现过暂停/未推进，尚不能确认超时原因，不据此声称发音回归全部通过。服务端14项首次通过，资源压力下复跑发生时间截止相关失败；发音/服务端源码未改，本次未扩大范围修复它们。

## 错词排行及循环释义更新

- 原动态词本改名「错词排行」，展示累计拼写错误次数，列表及默写按次数降序；同次数沿用时间顺序。开场及重新开始不受普通词本的乱序开关影响，保留原乱序偏好。
- 每次拼写错误在原子事务中累加，跳过未完成的词也统计；在错词排行里继续拼错只更新已有条目，不改变原有全程默写无错才移除的规则。
- 增加可选 wrongCount 数据，不更改数据库版本或旧记录。旧条目按已有历史错误记录统计，缺少记录至少计1次；旧版未保存的跳过错误无法准确追溯。导入旧备份仍可显示和排序。
- 右上关闭返回同站上一页；直接打开无站内前页时返回练习首页。
- 隐藏释义且循环练习时，第一次拼完后持续揭示本词中文，直到切词；跳回及重新开始清除揭示状态。下一词与预览的隐藏规则不变。
- 验证只覆盖6项关联场景：旧数据统计+排名默写+乱序开启/重新开始+移除，未完成错误计数和返回，直达关闭，3遍循环释义，快捷键切词清除，先错后改对不移除。6项最终分别通过；首次尝试有两项页面进入setup超时和一项测试误认Restart会暂停，未把这些失败隐藏或计作通过。
- 最终生产构建成功，4751原音频hash/同站端点检查及差异空白检查通过。未修改发音或服务端。npm test仍为占位脚本，不计入验收。

## 中文释义旁词性补充

原WANG C3/C4/C5/C11条目没有词性字段，旧页面仅渲染中文。新增离线匹配表，不修改原词库、音频、数据库或发音接口：同英文词、中文义项精确分段对应到现有词库标注；没有义项对应时仅使用现有来源一致的单一词性；无法对应或存在歧义则显示「词性待补充」。未对齐的a./n.合并表头不能错误归到其中一种词性。已自带词性及非英语词书保持原展示。

- 4,788条中补充2,551条：C3 1,041/1,135，C4 318/346，C5 406/1,569，C11 786/1,738。
- 2,237条待补充：无带词性来源2,093条，无法可靠对应当前中文义项144条；不是断言这些词没有词性。详细名单与方法计数见docs/word-parts-of-speech-report.json。
- n./adj.等随中文显示，包括已完成的上一个词；隐藏状态和下一个词预览不泄漏。循环3次的第一次正确后，中文及词性持续到切词。中文朗读仍仅使用原释义文本。
- 可重现生成命令：python3 scripts/build-word-parts-of-speech.py。5项数据匹配规则测试（包括错误合并表头）及2项实际页面针对性测试均通过，先看到缺少n./adj.的失败再补实现；未重跑无关整站功能。原npm test为占位脚本。
